# Lens Lab

An interactive 3D optics bench that teaches how camera focus works — thin-lens physics, circle of confusion and depth of field, rendered with three.js.

_Work in progress — see [PLAN.md](PLAN.md)._

```bash
npm install
npm run dev      # http://localhost:5173/lens-lab/
npm run build    # production build in dist/
npm test         # optics unit tests
```
